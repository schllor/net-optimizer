# 网络优化助手

面向电脑新手小白的 Windows 网络诊断与优化工具。无需任何网络技术知识，点几下按钮即可完成常见网络故障的排查与修复。

基于 **Python + PySide6 (Qt6)** 开发，界面采用黑白极简风格。

---

## 功能特性

| 功能 | 说明 |
| --- | --- |
| 一键诊断 | 自动检查网卡、IP、网关、DNS、互联网连通性、代理等多项状态（7 项检测并发执行），支持一键复制诊断报告 |
| 一键修复 | 刷新 DNS 缓存、重置 Winsock / TCP-IP、释放重获 IP、清除代理，修复后可一键重新诊断 |
| 网速测试 | 测量网络延迟（Ping）与上下行速度，并给出评级建议，测试过程可随时取消 |
| DNS 优化 | 批量并发测试常用 DNS 延迟，按速度排名并推荐最优 DNS，测试过程可取消 |
| Wi-Fi 检测 | 读取信号强度、信道、速率，并给出改善建议 |
| 局域网设备 | 扫描当前网络下的活跃设备，支持**自定义设备名称**、限速 / 封禁操作引导 |

### v1.6.0 / v1.6.1 / v1.6.2 / v1.7.0 / v1.7.1 / v1.7.2 优化要点

- **界面（v1.7.2）**：去掉系统自带的浅色标题栏，改为无边框窗口 + 自绘深色标题栏，可拖动、双击最大化，右侧为最小化 / 最大化 / 关闭；窗口四边仍可拖拽缩放，最大化时不会压住任务栏。

- **启动与开销（v1.7.1）**：去掉导入期 `platform.system()` 触发的 `cmd /c ver`（约 38ms）；「当前 DNS」改为进入 DNS 页再检测（约 43ms）；实时网速采样改用 `GetIfTable2`（每次约 0.7ms，psutil 约 8ms）；网速测试/下载器的 urllib 改为按需导入。实测冷启动导入耗时约 -22%、窗口构建约 -28%。
- **进度反馈（v1.7.0）**：任务启动时内容区顶部出现 3px 彗星进度条——未拿到百分比时循环扫过，收到真实进度后平滑推进，完成时补满并淡出；多任务并行取最大进度，下载暂停时自动隐藏，不占用页面布局。
- **体积精简（v1.6.2）**：打包时剔除未使用的 Qt 组件（QML / Quick / PDF / 软件 OpenGL 回退 / 图片解码 / 翻译包），EXE 由 52MB 降至 31MB（约 -41%），首次启动解压更快，功能与运行内存基本不变。
- **结构重构（v1.6.1）**：`main_window.py` 由约 3900 行降至约 220 行，窗口骨架抽到 `ui/shell.py`，九个功能页面拆到 `ui/pages/`，工作线程拆到 `ui/workers.py`，公共配色拆到 `ui/common.py`，并新增界面结构回归测试。
- **并发化**：诊断 7 项检测、DNS 批量测速、局域网主机名反查全部并发执行（实测诊断约 2 秒、10 个 DNS 约 2.2 秒），结果顺序保持不变。
- **可取消**：网速测试与 DNS 测速均支持中途取消，关闭窗口时后台线程在 2 秒内有序退出。
- **无感后台命令**：所有系统命令通过 `core/cmd_utils.py` 统一调用，不再闪现黑色控制台窗口；命令超时时返回已获得的部分输出。
- **数据安全**：历史记录与设备别名采用「临时文件 + `os.replace`」原子写入，别名走内存缓存（避免逐行读盘）；下载状态文件加锁并限频落盘。
- **修复更稳**：`ipconfig /release` 失败时中止后续步骤，避免把用户留在断网状态。
- **日志自清理**：自动删除 14 天前的日志文件。
- **易求助**：诊断结果一键复制为文本报告，修复完成后可一键重新诊断。

## 快速开始

### 方式一：直接运行（普通用户）

从 [Releases](../../releases) 下载 `网络优化助手.exe`，双击即可运行，**免安装**。

> 部分修复功能需要管理员权限。若修复失败，请右键选择「以管理员身份运行」。

### 方式二：从源码运行（开发者）

```bash
git clone <本仓库地址>
cd 源代码
pip install -r requirements.txt
python main.py
```

运行环境：Python 3.9+ / Windows 10 及以上（Qt6 已不再支持 Windows 7/8）。

---

## 从源码打包 EXE

```bash
cd 源代码
pip install pyinstaller
pyinstaller 网络优化助手.spec --noconfirm
```

产物位于 `dist/网络优化助手.exe`。

> **关于中文字体**：程序优先使用系统的微软雅黑 / 黑体等中文字体，仅当系统缺少中文字体时才回退到随包注册的 `fonts/simhei.ttf`。
> 由于 SimHei 属于微软 / 中易的**专有字体**，本仓库不包含该文件。若你需要完全脱离系统字体的独立打包，请自行将合法的字体文件放入 `源代码/fonts/` 目录。

## 技术栈

- **界面**：PySide6 (Qt6)，Fusion 风格 + 自定义 QSS 主题
- **系统信息**：psutil
- **网络操作**：调用系统 `netsh` / `ipconfig` / `ping` 等命令，封装于 `core/cmd_utils.py`
- **打包**：PyInstaller（单文件；排除 Qt3D / WebEngine / Multimedia / QML / PDF / 图片解码 / 翻译包等无关组件，EXE 约 31MB）

## 隐私与安全说明

本项目在设计上遵循**最小权限、最小采集**原则：

- **只读扫描**：局域网设备扫描基于系统 `arp -a` 的只读输出，不发送探测包、不修改任何路由配置。
- **不篡改路由器**：限速 / 封禁等操作不会直接修改路由器设置，仅复制目标设备的 MAC 地址并引导用户在路由器管理页自行操作。
- **数据仅存本地**：诊断历史、修复记录、设备自定义名称等全部保存在程序目录的 `data/` 文件夹内，**不上传任何服务器**，无遥测、无账号体系。
- **修复操作**：一键修复执行的是标准的网络重置命令（`ipconfig /flushdns`、`netsh winsock reset` 等），执行前均有二次确认，不会破坏系统。
- **仓库不含隐私数据**：`.gitignore` 已屏蔽 `data/` 目录、运行日志、构建产物与专有字体，仓库中仅包含源代码与文档。
