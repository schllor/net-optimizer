# 网络优化助手

面向电脑新手小白的 Windows 网络诊断与优化工具。无需任何网络技术知识，点几下按钮即可完成常见网络故障的排查与修复。

基于 **Python + PySide6 (Qt6)** 开发，界面采用黑白极简风格。

---

## 功能特性

| 功能 | 说明 |
| --- | --- |
| 一键诊断 | 自动检查网卡、IP、网关、DNS、互联网连通性、代理等多项状态（7 项检测并发执行），可复制或**导出报告** |
| 一键修复 | 刷新 DNS 缓存、重置 Winsock / TCP-IP、释放重获 IP、清除代理，修复后可一键重新诊断 |
| 网速测试 | HTTP 首字节延迟（P50/P95/抖动/丢包）+ 多流并发上下行，按稳定窗口计算速度，测试过程可随时取消 |
| DNS 优化 | 多轮热/冷域名查询，按 P95 排名，推荐最优 DNS，并校验 DoH 可用性；支持备份后恢复自动获取 |
| Wi-Fi 检测 | 原生 WlanAPI 读取信号强度、信道、速率；可扫描附近网络并给出信道建议 |
| 局域网设备 | 读取系统邻居表并用 ARP 验证在线状态，支持**自定义设备名称**、限速 / 封禁操作引导 |
| 多线程下载器 | 动态分块 + 自适应并发 + 多源加速，支持暂停 / 取消 / 断点续传，大文件自动提速 |
| 设置 | 测速时长、DNS 轮数、历史条数、下载并发连接、原生 API 开关、VPN 流量统计与界面动画 |

### v2.0.0 可读性、适配与真实数据

- **不再用演示数据冒充结果**：首页趋势、修复日志、DNS 推荐、Wi-Fi 邻区、设备列表、下载镜像、测速历史等示例数据全部下线；没有数据时显示「待检测 / 尚未扫描 / 暂无记录」，每个数字都能追溯到真实来源。
- **状态中枢**：新增 `AppState` 与 `NetworkSnapshot`，标题栏 / 状态栏 / 首页共用同一份真实网络快照（SSID、频段、信道、IP、网关、DNS、协商速率），后台按 30 秒刷新，不再各自读盘或写死。
- **排版与对比度**：移除全局 `font-size: 12px` 覆盖与各页 `_lock_fonts()` 补丁；最小文字 10px、正文 13px，三级灰字对比度全部达到 WCAG AA（≥4.5:1）。
- **响应式**：支持 1024×640 起、100%–200% 缩放；窄窗口自动切换图标侧栏、单列页面、页头动作换行和纵向滚动；窗口位置/大小/最大化状态自动记忆。
- **修复更诚实**：开始前列出需要管理员权限 / 需要重启 / 可回滚的项；代理设置修改前自动备份；删除假的「一键回滚」和预置修复成功日志；修复完成后可一键重新诊断。
- **首次引导**：首页增加 3 步引导（体检 → 修复 → 复查）；诊断完成后只修复检测到的问题，并自动复检。
- **更友好的反馈**：复制、导出、保存、DNS 应用等操作增加 Toast 提示；诊断结论、DNS 收益、测速分享/保存报告都改为真实数据。
- **DPI 与无障碍**：新增 PerMonitorV2 清单、图标按屏幕 DPR 渲染；自绘导航/开关支持键盘操作与焦点环。

### v1.9.0 下载器提速

- **动态分块 + 自适应并发**：不再固定 3 路等分。先开 4 路，监督线程每秒把「剩余最多的段」对半切开交给新连接；第 2/4/6 秒按实测速度决定是否继续加到设置上限（默认 8，最高 16），速度不再提升就停止加线程。
- **多源并发**：GitHub / Modrinth 等大文件会并发实测镜像吞吐，排名靠前的源同时承担不同分块；403/404 永久禁用该源，429/503 冷却 30 秒。
- **坏连接快速回收**：单连接 6 秒不足 8KB 直接断开换源；8 秒无进展的连接被掐断，剩余区间由新连接续上；全局停滞阈值由 60 秒降到 45 秒。
- **取消更利落**：取消时主动关闭活动连接，阻塞读立即返回，不再等读超时。
- **断点续传 v2**：按字节区间保存（`<文件>.netmeta.json`），换并发数、换镜像都能正确续传；取消时立即落盘。
- **设置入口**：下载页新增 ⚙ 按钮直达设置，可调节「下载并发连接」1–16 路。
- **正确性**：校验 206 与 `Content-Range` 是否匹配请求区间，统一 `Accept-Encoding: identity`，避免分段错位。

### v1.8.0 优化要点

- **原生探测（v1.8.0）**：Wi-Fi 状态/信道、附近网络扫描、当前 DNS 与局域网邻居改为 Windows 原生接口（WlanAPI、GetAdaptersAddresses、GetIpNetTable2 + SendARP），不再依赖 `netsh` / `ipconfig` / `arp` 的中文标签；原生调用失败时自动回退命令行，可用环境变量 `NETHELPER_NATIVE=0` 强制旧路径。
- **测速方法（v1.8.0）**：下载改为 4 路并发并按单流增长自适应加到 8 路，用 3 秒稳定窗口计算速度（剔除爬坡段），不再取「最慢源的耗时」；上传按确认字节统计；延迟优先用 HTTP 首字节（不受 ICMP 限速影响），输出 P50 / P95 / RFC3550 抖动 / 丢包。
- **DNS 方法（v1.8.0）**：每轮「1 个热门域名 + 1 个随机冷域名」，`NXDOMAIN` 视为正常响应，每台服务器多轮采样后按 P95 排序；`ping` 只作为「可连通」标记，不再参与排名；对前三名校验 DoH（RFC 8484），应用前备份原 DNS，失败自动回滚。
- **体验与可观测（v1.8.0）**：后台任务新增统一错误通道，异常时状态栏提示并复位按钮（不再永久禁用）；诊断/修复/设备扫描可取消；新增设置页、报告导出（Markdown / JSON / TXT）与历史记录详情；实时流量采样移出界面线程。
- **稳健性（v1.8.0）**：命令执行超时/取消不再把提示文字混入输出；下载线程带截止时间退出；SSRF 校验改用 `ipaddress` 并逐跳校验重定向；数据目录不可写时回退到 `%LOCALAPPDATA%`。

### v1.6.0 / v1.6.1 / v1.6.2 / v1.7.0 / v1.7.1 / v1.7.2 优化要点

- **界面（v1.7.2）**：去掉系统自带的浅色标题栏，改为无边框窗口 + 自绘深色标题栏，可拖动、双击最大化，右侧为最小化 / 最大化 / 关闭；窗口四边仍可拖拽缩放，最大化时不会压住任务栏。

- **启动与开销（v1.7.1）**：去掉导入期 `platform.system()` 触发的 `cmd /c ver`（约 38ms）；「当前 DNS」改为进入 DNS 页再检测（约 43ms）；实时网速采样改用 `GetIfTable2`（每次约 0.7ms，psutil 约 8ms）；网速测试/下载器的 urllib 改为按需导入。实测冷启动导入耗时约 -22%、窗口构建约 -28%。
- **进度反馈（v1.7.0）**：任务启动时内容区顶部出现 3px 彗星进度条——未拿到百分比时循环扫过，收到真实进度后平滑推进，完成时补满并淡出；多任务并行取最大进度，下载暂停时自动隐藏，不占用页面布局。
- **体积精简（v1.6.2）**：打包时剔除未使用的 Qt 组件（QML / Quick / PDF / 软件 OpenGL 回退 / 图片解码 / 翻译包），EXE 由 52MB 降至 31MB（约 -41%），首次启动解压更快，功能与运行内存基本不变。
- **结构重构（v1.6.1）**：`main_window.py` 由约 3900 行降至约 220 行，窗口骨架抽到 `ui/shell.py`，九个功能页面拆到 `ui/pages/`，工作线程拆到 `ui/workers.py`，公共配色拆到 `ui/common.py`，并新增界面结构回归测试。
- **并发化**：诊断 7 项检测、DNS 批量测速、局域网主机名反查全部并发执行（实测诊断约 2 秒、10 个 DNS 约 2.2 秒），结果顺序保持不变。
- **可取消**：网速测试与 DNS 测速均支持中途取消，关闭窗口时后台线程在 2 秒内有序退出。
- **无感后台命令**：所有系统命令通过 `core/cmd_utils.py` 统一调用，不再闪现黑色控制台窗口；命令超时时返回已获得的部分输出。
- **数据安全**：历史记录与设备别名采用「临时文件 + `os.replace`」原子写入，别名走内存缓存（避免逐行读盘）；下载状态文件加锁并限频落盘。
- **修复更稳**：`ipconfig /release` 失败时中止后续步骤，避免把用户留在断网状态。
- **日志自清理**：自动删除 14 天前的日志文件。
- **易求助**：诊断结果一键复制为文本报告，修复完成后可一键重新诊断。

## 快速开始

### 方式一：直接运行（普通用户）

从 [Releases](../../releases) 下载 `网络优化助手.exe`，双击即可运行，**免安装**。

> 部分修复功能需要管理员权限。若修复失败，请右键选择「以管理员身份运行」。

### 方式二：从源码运行（开发者）

```bash
git clone <本仓库地址>
cd Windows
pip install -r requirements-dev.txt   # 仅运行程序可用 requirements.txt
python src/main.py
```

运行环境：Python 3.9+ / Windows 10 及以上（Qt6 已不再支持 Windows 7/8）。

### 方式三：运行测试

```bash
pip install -r requirements-dev.txt
pytest
```

`tests/conftest.py` 会自动把 `src/` 加入导入路径，并以 `QT_QPA_PLATFORM=offscreen` 运行，无需真实显示器。

## 从源码打包 EXE

```bash
pip install -r requirements-dev.txt
cd packaging
build.bat
```

或手动执行：

```bash
pyinstaller packaging/网络优化助手.spec --noconfirm --workpath packaging/build --distpath packaging/dist
```

产物位于 `packaging/dist/网络优化助手.exe`。

> **关于中文字体**：程序优先使用系统的微软雅黑 / 黑体等中文字体，仅当系统缺少中文字体时才回退到随包注册的 `src/assets/fonts/simhei.ttf`。
> 由于 SimHei 属于微软 / 中易的**专有字体**，本仓库不包含该文件。若你需要完全脱离系统字体的独立打包，请自行将合法的字体文件放入 `src/assets/fonts/` 目录。

## 技术栈

- **界面**：PySide6 (Qt6)，Fusion 风格 + 自定义 QSS 主题
- **系统信息**：psutil（可选，用于流量统计兜底）
- **Windows 原生接口**：ctypes 调用 WlanAPI / IP Helper API，无需额外依赖；失败时回退 `netsh` / `ipconfig` / `arp`
- **打包**：PyInstaller（单文件；排除 Qt3D / WebEngine / Multimedia / QML / PDF / 图片解码 / 翻译包等无关组件，EXE 约 31MB）

## 隐私与安全说明

本项目在设计上遵循**最小权限、最小采集**原则：

- **只读扫描**：局域网设备扫描读取系统邻居表（`GetIpNetTable2` / `arp -a`），并对同子网设备发送标准 ARP 查询确认是否在线；不修改任何路由配置。
- **不篡改路由器**：限速 / 封禁等操作不会直接修改路由器设置，仅复制目标设备的 MAC 地址并引导用户在路由器管理页自行操作。
- **数据仅存本地**：诊断历史、修复记录、设备自定义名称、设置与导出报告等全部保存在程序目录的 `data/` 文件夹内（不可写时回退 `%LOCALAPPDATA%\网络优化助手`），**不上传任何服务器**，无遥测、无账号体系。
- **修复与 DNS 操作**：一键修复执行标准的网络重置命令（`ipconfig /flushdns`、`netsh winsock reset` 等），应用 DNS 前会备份原配置，失败自动回滚；所有写操作均有二次确认。
- **仓库不含隐私数据**：`.gitignore` 已屏蔽 `data/` 目录、运行日志、构建产物与专有字体，仓库中仅包含源代码与文档。
